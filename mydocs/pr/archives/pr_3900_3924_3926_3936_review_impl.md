- `b2905829a`: #3926의 PR 설명은 host 줄 높이 조건을 배제했다고 했지만 원 코드는 host 조건과 저장
  사다리 여유를 OR로 묶고 있었다. host 조건을 제거해 다음 실제 저장 `vpos`가 table와 outer margin을
  수용할 여유가 있는 경우로만 좁혔다. 또 #3900의 저장 위치 비교에서 synthetic line segment를 제외했고,
  positive·negative predicate 회귀를 추가했다.
- `c6f2ddcb3`: #3936의 미주 없는 body section 경계와 `ColumnDef` 삽입 idempotence 회귀를 추가했다.
