## PR·merge 이후 절차

1. LFS 대상 사전 판독 뒤 upstream의 review/planet6897-20260803 branch로 push한다.
2. devel 대상 통합 PR을 만들고 원 PR 7개, maintainer 보정 2개, 검증 범위·제한을 본문에 적는다.
3. 생성된 PR head의 Actions와 mergeability를 최신 상태로 확인한 뒤, 작업지시자 지시에 따라 merge한다.
4. merge 뒤 관련 issue 상태, 원 PR close, devel 동기화, review branch 및 전용 target 정리를
   post_merge 절차로 수행한다.
